# Global Countries EDA

## Overview
This project explores demographic, political, health, economic, and environmental indicators across 194 countries using Python and Pandas.

## Dataset
The dataset contains 64 features including:
- Population
- GDP
- Democracy Score
- Life Expectancy
- Internet Access
- Energy Consumption
- CO₂ Emissions

## Technologies Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Analysis Performed
- Dataset inspection and cleaning
- Population and demographic analysis
- Democracy and governance analysis
- Health indicators analysis
- Economic analysis
- Energy and environmental analysis

## Key Findings
- Population is concentrated among a small number of countries.
- Democracy scores vary significantly across regions.
- Life expectancy differs substantially across continents.
- Renewable energy adoption varies across countries.
